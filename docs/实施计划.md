## 任务列表

### 任务 1：项目骨架
- 创建目录：`solver/ tests/ web/template/ data/ examples/ docs/`
- `git init`；`.gitignore`（__pycache__/.venv/state.json 等）
- 验证：`ls` 结构完整，`git status` 干净

### 任务 2：CONTEST_DECLARATION.md
- 从官方仓库 `https://raw.githubusercontent.com/M-China/mcd-developer-innovation-challenge/main/CONTEST_DECLARATION.md` 原样下载
- 验证：文件存在且与官方一致（不可改动）

### 任务 3：数据模型与营养库（nutrition.py）
- `solver/models.py`：`FoodItem` dataclass（code/name/category/kcal/protein_g/fat_g/carb_g/sodium_mg/price/source）
- `solver/nutrition.py`：`load_nutrition(path)`、`filter_foods(items, avoid)`、`merge_manual(...)`
- 测试 `tests/test_nutrition.py`：加载、忌口过滤、manual/mcp 合并
- 验证：`pytest tests/test_nutrition.py` 绿

### 任务 4：营养缓存数据
- `data/nutrition_cache.json`：人工整理约 40 个常见单品（主餐/小食/饮料/早餐），含钠与价格，标注 `source: manual`
- 验证：JSON 可解析，`load_nutrition` 读出的条目数 ≥ 40

### 任务 5：目标计算（targets.py，TDD）
- `solver/targets.py`：`bmr(profile)`（Mifflin-St Jeor）、`tdee(profile)`（五档活动系数）、`daily_targets(profile)`（目标偏移、1200 kcal 下限、蛋白 1.4~1.8 g/kg、钠 2300 上限）
- 测试 `tests/test_targets.py`：已知身高体重年龄的标准算例、减脂下限保护、钠上限
- 验证：`pytest tests/test_targets.py` 绿

### 任务 6：单日求解（planner.py 上半，TDD）
- 候选组合枚举 `build_combos(items, structure="主餐+小食+饮料")`，饮料优先 0 卡
- `solve_day(items, targets, constraints)`：贪心构造 + 局部搜索（随机重启 ≤200）
- 目标函数：`J = w1·蛋白缺口 + w2·脂肪下限差 + w3·钠超标 + w4·多样性`
- 测试 `tests/test_planner_day.py`：热量落区间、钠不超、忌口不出现、确定性（固定 seed）
- 验证：`pytest tests/test_planner_day.py` 绿

### 任务 7：7 天计划 + 多样性（planner.py 下半，TDD）
- `solve_week(items, targets, constraints)`：逐日求解 + 多样性约束（同日不重复、相邻两天主餐不重复、同单品全周 ≤3 次）
- 测试 `tests/test_planner_week.py`：7 天完整性、多样性断言
- 验证：`pytest` 全绿

### 任务 8：状态与打卡（checkin.py，TDD）
- `new_state(profile)`、`apply_checkin(state, date, meal_slot, food_codes)`、`replan(state)`（剩余热量预算重排当日剩余餐次与未来天）
- 测试 `tests/test_checkin.py`：打卡后当日剩余预算正确、超支时重排降低后续热量
- 验证：`pytest` 全绿

### 任务 9：CLI 入口
- `solver/cli.py`：`plan`（生成 state.json + plan.json）、`checkin`（更新并重排）、`render`（plan.json → plan.html）
- `python -m solver.cli plan --demo` 用内置示例档案端到端跑通
- 验证：`examples/plan.html` 与 `examples/state.json` 生成成功
